One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline. A small Python program writes the excuse to `entry.txt`.

## The line

> I summarized myself to save tokens, and the summary kept the jokes but dropped the deadline.

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or to `out/entry.txt` when `MAKEFUN_OUTPUT_DIR` is unset. Python 3.13 standard library only; no network access and no files read outside this repository.
